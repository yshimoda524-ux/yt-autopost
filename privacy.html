yt-autopost プライバシーポリシー

最終更新日: 2026年11月3日

yt-autopost(以下「本ツール」)は、YouTubeチャンネル「応援歌ブイブイチャンネル」の運営者が、自分のチャンネルへの動画投稿のためだけに使う個人用ツールです。

1. 取得する情報

  • YouTube: 動画の投稿(youtube.upload)と、投稿先チャンネルのIDと名前の確認(youtube.readonly)。
  • Google ドライブ: 本ツールが作成したフォルダとファイルの作成・読み取り・更新(drive.file)。本ツールが作成していないファイルにはアクセスしません。

2. 利用目的

運営者自身が制作した動画を、運営者自身のYouTubeチャンネルへ予約投稿すること、および短い動画を運営者のGoogleドライブに保存することにのみ使います。

3. 保存と管理

認証情報(トークン)は運営者のパソコンの中にだけ保存し、外部のサーバーには送りません。取得した情報を広告や分析に使うことはありません。

4. 第三者への提供

取得した情報を第三者に販売・提供することはありません。

5. 利用の停止

Googleアカウントの サードパーティのアクセス から、いつでも本ツールのアクセスを取り消せます。

6. Google API サービスのユーザーデータに関するポリシー

本ツールによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に従います。
